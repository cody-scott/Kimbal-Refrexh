# Kimball Lab (dbt)

The companion dbt project for the Kimball Refresh study site: a complete Kimball dimensional warehouse for the
fictional retailer *Cascade Outfitters*, written for **Snowflake**.

| Folder | Contents |
|---|---|
| `seeds/` | Raw source data, generated by `scripts/generate_seeds.py` |
| `models/staging/` | `stg_` views: rename, cast, clean |
| `models/intermediate/` | `int_` views: SCD history, allocations |
| `models/marts/` | `dim_`, `fct_`, `bridge_`, `agg_` tables: the dimensional model |
| `models/semantic/` | dbt Semantic Layer models and metrics |
| `snapshots/` | dbt snapshots (Type 2 by observation) |
| `analyses/` | Business-question queries used in the lessons |
| `tests/` | Singular tests and the `scd2_valid_ranges` generic test |

```bash
pip install -r requirements.txt
cp profiles.example.yml ~/.dbt/profiles.yml   # set SNOWFLAKE_* env vars
dbt deps && dbt seed && dbt build
```

Without Snowflake: `dbt compile --profiles-dir ci && python scripts/smoke_test_duckdb.py`.
