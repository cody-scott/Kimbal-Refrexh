# Module 8: Practice

Reading about dimensional modeling and *doing* it are different skills. This module is the doing.

| Practice set | Format | Time |
|---|---|---|
| [Design exercises](/practice/design-exercises) | A business scenario → you design the star (four steps, ERD, SCD choices) | 20–40 min each |
| [Spot the error](/practice/spot-the-error) | Broken models and queries, to find and fix | 5–10 min each |
| [SQL drills](/practice/sql-drills) | Business questions to answer against the lab in Snowflake | 10 min each |
| [Interview questions](/practice/interview-questions) | Conceptual questions with model answers | |
| [Capstone: returns](/practice/capstone) | Design and build a new bus-matrix row in the lab dbt project | a weekend |

**How to practice:** attempt each exercise *before* opening the solution. Write your answer down, even a sketch.
Then compare: what did you miss, and why?
