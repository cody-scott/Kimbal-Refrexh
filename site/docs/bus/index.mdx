# Module 5: The enterprise bus

Individual stars are useful. A set of stars that **share conformed dimensions** is a data warehouse. The
**enterprise data warehouse bus architecture** is Kimball's answer to "how do we build an integrated warehouse
incrementally, one business process at a time, without a giant upfront enterprise model?"

The metaphor: like a computer's bus, conformed dimensions are a **standard interface**. Any new business
process "plugs in" by using the conformed dimensions, and is immediately comparable with everything else.
