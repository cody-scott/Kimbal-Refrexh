# Module 7: Case studies

The Data Warehouse Toolkit teaches through **industry case studies**, each introducing techniques in the context
where they naturally arise. This module follows the same structure. Each case study goes through the four
steps, a bus-matrix row, the design, the dbt implementation (where built) and the queries that matter to that
business.

## Built in the lab (Cascade Outfitters)

| Case study | DWT3 chapter | Key techniques |
|---|---|---|
| [Retail sales](/case-studies/retail-sales) | 3 | Four-step process, atomic grain, date/product/store/promotion, factless coverage, degenerate dims |
| [Inventory](/case-studies/inventory) | 4 | Periodic snapshots, semi-additive facts, transaction vs snapshot, drill-across |
| [Procurement](/case-studies/procurement) | 5 | Single vs multiple transaction facts, accumulating snapshot, SCD types |
| [Order management](/case-studies/order-management) | 6 | Role-playing dates, junk dims, allocation, currencies, fulfillment pipeline |
| [Accounting](/case-studies/accounting) | 7 | GL snapshots, ragged chart of accounts, budget vs actual |
| [Customer relationship management](/case-studies/crm) | 8 | Rich customer dimension, mini-dimensions, multivalued bridges, behavior segments |
| [Human resources](/case-studies/human-resources) | 9 | Employee profile Type 2, headcount snapshot, recursive hierarchy |
