# Kimball techniques index

The Kimball Group publishes an official list of
[dimensional modeling techniques](https://www.kimballgroup.com/data-warehouse-business-intelligence-resources/kimball-techniques/dimensional-modeling-techniques/),
which Chapter 2 of *The Data Warehouse Toolkit* (3rd ed.) summarizes. This index maps each one to where it's taught
here and where it appears in the lab. Chapter numbers refer to the 3rd edition; Ch. 2 covers every technique in
summary form.
